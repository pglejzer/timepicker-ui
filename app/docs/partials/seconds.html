Seconds

Optional seconds unit (clock.showSeconds, off by default) in every mode, layout, plugin and theme. Every card prints the last event and, on confirm, getValue().

  • Values: 24h 14:30:15, 12h 02:30:15 PM; HH:MM means :00.
  • clock.incrementSeconds: 1, 5, 10, 15, 20, 30 · clock.autoSwitchToSeconds (default true) · clock.disabledTime.seconds and clock.disabledTime.ranges with seconds.
  • Label: labels.second · event select:second / callbacks.onSelectSecond.

Seconds - API playground

getValue(), setValue() and update() on a live picker (#seconds-api, 24h).

Seconds - event log

Every event of #seconds-events (12h, clear button) plus callbacks.onSelectSecond, newest first.

Seconds - all themes

Clock 12h, clock 24h, wheel 12h, compact-wheel 24h and popover 12h in each of the 12 themes. Input ids: #seconds-theme-<theme>-<variant>.
