Open from a button

Wrap the input and a button in one element, put data-open on the button and pass the wrapper to TimepickerUI. Only the button opens the picker. A click in the field places the cursor, so the time can be typed, and the picker reads the typed value when it opens.

  • When the wrapper has a data-open element, the input no longer opens the picker. Elements that share the first data-open value all open it.
  • Use a real <button type="button">: Enter and Space open the picker too.
  • An icon-only button needs an aria-label.
  • behavior.returnFocus: true moves focus back to the field after OK, Cancel or Escape.

HTML

<div id="open-button-end">
  <input id="open-button-end-input" value="10:30 AM" />
  <button type="button" data-open="open-button-end" aria-label="Choose time">
    <span class="material-icons" aria-hidden="true">schedule</span>
  </button>
</div>

JavaScript

const picker = new TimepickerUI('#open-button-end', {
  behavior: { returnFocus: true },
});
picker.create();
